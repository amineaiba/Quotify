# Architecture Decision Records

One file per real, hard-to-reverse decision — not every choice, just the
ones a teammate (or future us) would reasonably ask "why did we do it this
way?" about.

- Filename: `NNNN-short-title.md`, numbered in order.
- Once accepted, a record is never edited — a changed decision gets a new
  ADR that supersedes the old one (link both ways).
- Keep it short: context, decision, consequences. No need for a template
  beyond that.
